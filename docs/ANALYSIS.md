# Video analysis / 视频解析

Use `framecheck analyze video.mp4 -o NEW_FOLDER` or the desktop **解析单个视频** entry.

The engine detects hard cuts from downscaled HSV changes, estimates global 2D motion from sparse optical flow and RANSAC, and extracts supplied/embedded subtitles or performs local speech recognition. It decodes actual frame presentation timestamps. Source videos are preserved.

## Outputs

| File | Purpose |
| --- | --- |
| `report.html` | Offline evidence viewer; editable semantic notes and export buttons |
| `analysis.json` | Complete execution state, original shots, timing, motion, transcript provenance and delivery units |
| `shots.csv`, `motion.csv` | Shot index and sampled motion-fit evidence |
| `transcript.srt`, `transcript.txt` | Timed dialogue; empty files do not imply a silent video when transcription failed |
| `storyboard.json/md/csv` | Generic reusable shot notes |
| `breakdown.txt` | One structured block per 4–15 second unit, using the original aspect |
| `keyframes/`, `units/` | Shot-start images and timestamped start/middle/end unit images |
| `clips/` | Optional re-encoded shot clips when `--export-clips` is selected |

The **整体导演设计** section contains only **画面风格**. Units contain no video continuation method, future-video starting state or production handoff. Source shot times are never stretched to fit a fixed duration. Long uncut shots may span units; very short sources stay short.

Visual semantics are not generated by OpenCV. Empty style, setting, action and expression fields mean **not analyzed**. Fill them after viewing, or use the agent skill with actual visual inspection. Do not infer specific equipment, identity, motive or unseen events from technical metrics.

## Controls

- `--threshold 27`: cut sensitivity; lower values find more candidate cuts.
- `--min-shot-seconds 0.35`: suppress closer candidate boundaries.
- `--analysis-size 480`: longest decoded analysis edge (160–1280 pixels); comparison still uses original resolution.
- `--motion-fps 8`: motion sample rate. Fit support is not an accuracy percentage.
- `--transcript auto|subtitles|asr|none`: auto uses text subtitles before speech.
- `--subtitles FILE.srt`: supplied UTF-8 subtitle timeline relative to the video's first frame.
- `--subtitle-stream N`, `--audio-stream N`: absolute ffprobe stream indices; default is the first suitable track.
- `--model base`: built-in Whisper name or local CTranslate2 model directory. CPU int8 inference is used.
- `--language zh`: optional language code; default auto-detects.
- `--offline`: prohibit speech-model downloading; missing model yields a partial report, not a fake transcript.
- `--max-frames N`: explicitly selected range, never whole-video acceptance.
- `--export-clips`: H.264/AAC re-encoding at detected boundaries; this changes encoding and uses extra disk space.

Model download is the only network operation in analysis. FFmpeg media inputs are local; no video upload or API key is required. Agent inspection of selected frames follows that agent provider's privacy settings, independently of this CLI.

Hard cuts, camera estimates and ASR can be wrong. Fades, flashes, rapid action, dominant moving subjects and low texture require review. A camera pan, dolly, digital transformation or object motion cannot always be separated from pixels alone. Burned-in subtitle OCR and speaker diarization are not implemented. HDR PQ/HLG inputs are rejected.

## Methods and implementation references

The independently implemented image-motion measurements use [OpenCV optical flow](https://docs.opencv.org/4.x/dc/d6b/group__video__track.html) and [partial affine RANSAC](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html). Local transcription uses [faster-whisper](https://github.com/SYSTRAN/faster-whisper). [FFmpeg](https://ffmpeg.org/documentation.html) handles media decoding, subtitle extraction and optional clip export. These links document components; they do not certify FrameCheck's output accuracy.
